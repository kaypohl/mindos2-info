Datenschutzerklärung – MindOS2

MindOS2 ist eine private Anwendung für den persönlichen Gebrauch. Sie wird auf einem eigenen Server des Betreibers betrieben und ist nicht für die Öffentlichkeit bestimmt.

Welche Google-Daten verwendet werden

Mit ausdrücklicher Zustimmung des Betreibers greift MindOS2 auf Google Tasks zu (Berechtigung „Aufgaben ansehen, bearbeiten, erstellen und löschen"). Es werden ausschließlich die Aufgaben des eigenen Kontos gelesen und auf Anweisung des Betreibers angelegt, geändert, abgehakt oder gelöscht.

Speicherung

Der Zugangsschlüssel (Refresh-Token) wird ausschließlich auf dem eigenen Server des Betreibers gespeichert. Aufgabeninhalte werden zur Anzeige abgerufen; lokal werden nur Zusatzangaben wie Priorität und Projektzuordnung gespeichert.

Weitergabe

Daten aus Google Tasks werden nicht an Dritte weitergegeben, nicht verkauft, nicht für Werbung verwendet und nicht zum Training von KI-Modellen genutzt.

Widerruf und Löschung

Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden. Der lokal gespeicherte Zugangsschlüssel kann auf dem Server gelöscht werden.

Die Nutzung von Google-Daten durch MindOS2 entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung.
